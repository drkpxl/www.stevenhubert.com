Joy Rush is a retro-styled skiing game that ran at Ikon Pass events through the 26/27 on-sale season. The agency built the web version that sat on ikonpass.com behind the Find Joy campaign. To bring the game into physical activations I built a native console version on Raspberry Pi and Intel NUC hardware, dusting off my Linux and Python skills in the process.

![Joy Rush arcade cabinet at an Ikon Pass event](https://placehold.co/1200x675?text=Arcade+cabinet+at+event)
*A Joy Rush cabinet at an Ikon Pass on-sale event*

The console build started as a one-off prototype for a single event. Once the sales and marketing teams saw how players responded, the order book grew. There are roughly ten cabinets in the wild now, showing up at on-sale gatherings and passholder events through the season.

The hardware split was a small but real product decision. Raspberry Pi units went into the smaller, more portable cabinets where weight and shipping mattered. Intel NUC went into the flagship installations where the team wanted higher-fidelity graphics and faster response. Both ran the same Python game loop, tuned for the target hardware.

The interesting design problem was translating the game from a one-handed mobile web experience into a two-handed physical arcade. The web version optimized for a quick tap on a phone. The arcade version had to give passholders standing in front of it a real game session, fifteen to thirty seconds of meaningful play, ideally with a clear enough hook that they walked away talking about it. That meant tuning the difficulty curve, the visual feedback, and the audio in ways the web version did not need to.

The game pulls in pixel-art power-ups tied to real Ikon Pass partners (Blenders, US Ski & Snowboard, Under Canvas) so the in-game promotion lines up with the brand activations running around it. The whole thing was a chance to ship something physical, with hands on a keyboard, attached to a brand moment I do not usually get to express this way.
